CF-207 replaces the old board with a new package at `claude/coder-fleet/boards/` (plural; the old one is `board/`). Group A (CF-207.2, reviewed 2026-11-14) is storage only: `~/.config/boards/<PREFIX>/`, key recorded in config.yml (normalised origin URL or real path of the git common dir), ids.json high-water mark, events.log. It is not wired into any hook yet; MCP, web UI and the `boards` binary come in later groups (G ships the CLI/binary, B owns locks and atomic writes).

**Why:** the spec (docs/specs/CF-207.md on the state branch) assigns concurrency (rekey race, allocateId read-modify-write, non-atomic config writes) to group B, so a group A review should not block on them; check that group B's card actually covers the rekey lock.

**How to apply:** check-all runs it as section `boards` via `bun test --timeout=60000` with no install; check-all-ci-bun and check-all-lock scratch trees list it. Settled at the human's word on 2026-11-14: folder named by prefix, prefix immutable and machine-unique, one board per repo. Open for a decision: host-alias SSH remotes (`git@github-work:o/r`) and path-case folding both split one repo across two boards.
