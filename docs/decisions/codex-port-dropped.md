# The Codex port was dropped, and where to get it back

The human ordered Codex dropped as a harness on 22 October 2026. The `codex/` port was removed in commit 330d591 on 5 November 2026, and the repo has named Codex nowhere outside the board's history and this note since.

To recover the port, check out `codex/` from commit 515d5a0, the last commit that has it: `git checkout 515d5a0 -- codex`.
