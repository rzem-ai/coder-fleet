# Reviewing the CF-12.1 spike: where one-run evidence met a design decision

2026-09-27, reviewer, CF-12.1: round 1 review of the throwaway-plugin harness and its findings file.

## What the run was

A read-only review of branch `cf-12.1-spike` against `origin/main`. The branch holds a harness under `claude/scripts/spike/cf-12.1/` and the findings in `docs/findings/CF-12.1-claude-code-behaviours.md`. The brief put the budget on two things: whether each verdict follows from its evidence, and whether the harness could hurt the machine it ran on.

## What was tried and abandoned

The first idea was to recheck the quoted excerpts against the raw logs. That was dropped: the scratch area was torn down after the batch, and only redacted excerpts were committed. What was left was checking the evidence's provenance through the code. For each quoted field, which script could have written it, and under what condition? That approach produced the main finding: E2b quotes a payload field and a transcript that only `capture-stop.sh` writes, and only when the hook the same paragraph says never fired.

The next idea was to confirm whether the selftest leaves anything behind. Running it was out of scope for this role, so the check was `ls .claude/worktrees/` instead. It turned up an empty `some-session` directory with a timestamp inside the scripter's run.

A third idea was that `deny-real` loading the real plugin might move a real board card through an inherited `CODER_FLEET_BOARD_PAGE_ID`. That was dropped after reading `board-subagent-start.sh`. The denied spawn never starts, and the scratch working directory has no `.boards/` to write to.

## What the constraint turned out to be

Sample size, not harness quality. The harness is careful, and its JSON bug was caught and fixed honestly. But three of the question (2) cells rest on one run each. E2c also changes the model and the instruction at once, and the "no hook safety net" consequence rests on an absence nobody reproduced. The spike format has no "rerun before concluding" step for a negative result, only for a failed control.

## What to do differently

A spike whose evidence is torn down should commit a manifest of raw log filenames next to the findings: no content, just which `stop-*` and `transcript-*` files existed. That would have settled the E2b question in one read. For any "X does not happen" verdict, plan a second run up front. And vary one thing per cell.
