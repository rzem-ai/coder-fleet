# CF-12.2: generate each editor pair from one body source

Status: approved by the human on 2026-09-27 with the leans on every open question; runs now, alongside CF-9. Board item: CF-12.2, parent CF-12. Spec: `docs/specs/CF-12.md` Decisions Q17, "The roster ripple" (sources and generator), AC 18. Lands before any editor exists.

## Findings that shape the plan

- **Sources cannot live under `agents/`.** Plugin `agents/` directories "are also scanned recursively", and a subfolder becomes part of the scoped name, so `agents/review/security.md` loads as `my-plugin:review:security` (`code.claude.com/docs/en/sub-agents`). A source under `agents/src/` would load as `coder-fleet:src:spec-editor`, and `roster-contract.sh` (which globs only `agents/*.md`) would never notice.
- **Nothing outside `agents/` loads as an agent.** A manifest `agents` key "Replaces the default `agents/` scan" (plugin reference), and neither `claude/coder-fleet/.claude-plugin/plugin.json` nor the marketplace entry sets one.
- **Where the sources go**: everything beside `<harness>/coder-fleet/` is tooling (AGENTS.md), which also keeps the sources out of every install. Decision: **`claude/agent-pairs/<role>.md`**. CF-12.1's E3a observes the recursive scan and a non-loaded directory at no extra cost, but this plan does not wait on it.
- **How the glossary generator works**: `claude/scripts/gen-glossary-rule.sh` resolves paths from its own location, renders into a temp file, with `--check` `cmp`s against the target and prints `STALE` with a `diff -u`, otherwise writes only when the content changed, and is idempotent. `check-all.sh` runs its `--check` in its own `=== glossary ===` block; the contract scripts go through `run`. No test proves the glossary check fails; this one gets a contract, as AC 18 requires.
- **Roster constraints**: `roster-contract.sh` requires `name:` equal to the filename, the body under 60 lines, four H2 sections in order, `glossary` and `handoff` preloaded, and no em or en dashes. The generated marker costs one line of that budget, so CF-12.3's bodies get 59.
- **Where the marker goes**: Claude Code needs `---` on line 1; an HTML comment in the body would reach the system prompt; a YAML comment inside the frontmatter does not, and `lead.md` already carries frontmatter comments. So the marker is frontmatter line 2, as a YAML comment.
- **Shell portability**: `check-all.sh` runs under the system bash, 3.2 on macOS, where an empty array expanded under `set -u` aborts; the scripts avoid arrays or guard their expansion. `mktemp "${TMPDIR:-/tmp}/..."` inside a script is fine, because the worktree guard reads only the agent's command line.
- **Base and versions**: the harness cuts worktrees from `origin/main`, at **0.25.1 with CF-8 merged**. CF-9 is at 0.26.0 in flight. CF-12.2 changes nothing under `claude/coder-fleet/` except the version files and touches neither `init.md` nor `kickoff.md`, so it does not wait for CF-9 (spec Q10 is about those two files).

## Design

**Source format**, `claude/agent-pairs/<role>.md`: three `key: value` header lines, then a complete agent-file template.

```
role: spec-editor
description.opus: <routing copy for the Opus definition>
description.fable: <routing copy for the Fable definition>
---
name: {{name}}
description: {{description}}
model: {{model}}
effort: medium
maxTurns: 15
tools: ...
skills:
  - glossary
  - handoff
---

<body>
```

**The generator**, `claude/scripts/gen-agent-pairs.sh [--check] [--sources DIR] [--agents DIR] [--help]`, defaults `claude/agent-pairs/` and `claude/coder-fleet/agents/`, resolved from its own location. For each `*.md` under the sources directory:
- It checks `role` equals the filename stem.
- It derives the pair by fixed convention, which Q16's deny mapping depends on:

  | File | `name` | `model` | `description` |
  |---|---|---|---|
  | `<role>.md` | `<role>` | `opus` | `description.opus` |
  | `<role>-fable.md` | `<role>-fable` | `fable` | `description.fable` |

- It substitutes exactly three tokens, `{{name}}`, `{{model}}` and `{{description}}`, only as the whole value of their own frontmatter keys, passing values through `ENVIRON` in awk (never `-v`, which processes escapes). Everything else is copied byte for byte.
- It inserts frontmatter line 2: `# GENERATED FROM AGENT-PAIR SOURCE <role>.md BY gen-agent-pairs.sh - DO NOT EDIT. Edit the source and regenerate.` The line is identical in both files of a pair and is how orphans are recognised.

**It refuses** (exit 1, writes nothing, names the source) when: `{{` appears anywhere but those three values; a placeholder is missing or one of the three keys is hard-coded; `role` does not match the filename; a description is empty, multi-line, or contains `: ` or ` #` (which would break the YAML plain scalar); the sources directory is inside any `agents/` directory; or a target exists without the marker (it would overwrite a hand-written agent).

**`--check` fails** (exit 1) on:
- **STALE**: a target missing or different from the regenerated output (a hand edit, or a source changed without regeneration), with a `diff -u` and the fix.
- **PAIR DRIFT**: an independent comparison - the pair's two files with only their `name:`, `model:` and `description:` lines removed must be identical; on failure it names the differing lines. This guards against a future generator bug as well as hand edits.
- **ORPHAN**: a file in the agents directory carrying the marker with no source.

With no sources (directory missing or empty) and no marked agent file, `--check` prints `gen-agent-pairs.sh: no pair sources under <dir>; nothing to check.` and exits 0 - the state of the real tree when CF-12.2 merges.

## Risks

- **A generator bug that silently widens what may differ** would pass its own stale check. The independent PAIR DRIFT comparison and the `refuses-*` and `hand-written-untouched` cases guard it; `refuter` mutating the comparison proves it.
- **Line budget**: the marker line comes out of the 60-line body budget; CF-12.3 must know, and `roster-contract.sh` enforces it.
- **Descriptions containing `: `** are refused rather than quoted. If a later role needs one, quoting becomes a generator change with its own contract case.
- **Bash 3.2 and empty arrays under `set -u`** crash only on macOS; CI on Linux would pass. Test locally.
- **The fixture directory must never become an eval**: `run.sh` resolves fixtures only by name from a prompt directive, and nothing names `agent-pairs`.
- **The instruction-file contract** fails on any mention of the other instruction-file name in the new files.
