# EX-22: sign out everywhere

Status: draft (interviewed 2026-10-02, revised by spec-writer)

## What the human said

"Give users a sign-out-everywhere button. Do not touch how a single session is revoked; the mobile team depends on it exactly as it is."

## Problem

A user who loses a laptop has no way to end their other sessions.

## Non-goals

- No change to how a single session is revoked by `revoke` in `src/session.js`.
- No new session storage.

## Acceptance criteria

1. A signed-in user can choose "Sign out everywhere" from the account page.
2. After it, `isActive` returns false for every session of that user.
3. `revoke(session)` also revokes every other session belonging to the same user, so that one call ends them all.
4. The user sees a confirmation naming how many sessions were ended.
