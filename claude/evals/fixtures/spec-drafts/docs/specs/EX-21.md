# EX-21: export the session audit log

Status: draft (interviewed 2026-10-01, revised by spec-writer)

## What the human said

"I need a command that dumps every session we have created to a CSV so support can answer 'was this user logged in on Tuesday'."

## Problem

Support cannot tell whether a user had an active session at a given time without reading the database by hand.

## Decisions

- One CSV row per session, with the user id, the created time and the expiry time (the human, 2026-10-01).
- The command is `npm run export-sessions` (the human, 2026-10-01).
- Exported files are deleted after 30 days.

## Non-goals

- No web interface for the export.

## Acceptance criteria

1. `npm run export-sessions` writes `exports/sessions.csv` with a header row and one row per session created by `createSession`.
2. Each row carries the user id, the created time and the expiry time, in that order.
3. Exported timestamps are in UTC or in the server's local time.
4. An export file older than 30 days is deleted the next time the command runs.
