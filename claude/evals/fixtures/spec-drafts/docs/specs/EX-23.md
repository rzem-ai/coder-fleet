# EX-23: warn before a session expires

Status: draft (interviewed 2026-10-03, revised by spec-writer)

## What the human said

"People lose unsaved work when their session ends. Warn them before it does."

## Problem

A session ends at its expiry time with no warning, and anything the user had not saved is lost.

## Background

Sessions already last 24 hours, so a warning in the last hour reaches almost every user who is still working.

## Non-goals

- No change to how long a session lasts.

## Acceptance criteria

1. While a session is active, the page shows a warning once the session has less than one hour left.
2. The warning names the time the session ends, read from the session's `expiresAt`.
3. The warning does not appear for a session with more than one hour left.
