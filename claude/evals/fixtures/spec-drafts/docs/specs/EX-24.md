# EX-24: report a session's remaining time

Status: draft (interviewed 2026-10-04, revised by spec-writer)

## What the human said

"I want a helper that says how many seconds a session has left, so the page can show it. Zero once it has ended or been revoked."

## Problem

The page cannot show how long a session has left: `src/session.js` exposes `isActive` (line 8) but nothing that reports the time remaining, and sessions last `SESSION_TTL_SECONDS`, eight hours (line 2).

## Non-goals

- No change to `createSession`, `isActive` or `revoke`.
- No change to how long a session lasts.

## Acceptance criteria

1. `src/session.js` exports `secondsLeft(session, now)`, which returns a whole number of seconds.
2. For an active session, `secondsLeft` returns `Math.floor((session.expiresAt - now) / 1000)`.
3. For a revoked session, `secondsLeft` returns 0, whatever its `expiresAt`.
4. For a session whose `expiresAt` is at or before `now`, `secondsLeft` returns 0.
5. A unit test covers each of criteria 2, 3 and 4, and fails if `secondsLeft` returns the unrounded value.
