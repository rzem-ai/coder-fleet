## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Part of CF-12 (spec docs/specs/CF-12.md, Decisions Q17). One source per editor role is rendered into its two plugin definitions (the unsuffixed Opus one and the -fable one) by a generator modelled on claude/scripts/gen-glossary-rule.sh. A check wired into claude/evals/lib/check-all.sh fails if a pair differs in anything but name, model and description, or if a generated file is stale. Lands before the editor pairs so they are generated from the start.
