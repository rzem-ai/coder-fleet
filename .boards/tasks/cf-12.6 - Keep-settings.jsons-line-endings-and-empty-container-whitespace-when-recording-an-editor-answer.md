## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Polish sub-issue for CF-12.5, from the second refuter on its fix round (2026-10-07). `claude/coder-fleet/scripts/editor-models.py` `set` inserts the deny entries into `.claude/settings.json`'s own text, and no input changes the file's meaning. Byte-level points left: in a CRLF file the inserted lines end in a bare LF (probes crlf_deny, crlf_nodeny, crlf_noperms), leaving mixed line endings; filling an empty `{ }` or `[ ]` rewrites the whitespace between the brackets (top_empty_ws loses one space). Test gaps: inserting into a non-empty multi-line deny array (a mutant that appends on the last item's line survives the contract), and the re-parse guard, which no test makes fire and may be unreachable for any input json.loads accepts. AGENTS.md insertion already keeps CRLF. Build phase put these here instead of a second fix round. Not ordered by the human.
