## Description

Part of CF-12 (spec docs/specs/CF-12.md: Decisions Q4, Q5, Q13; "The four agents"). tech-editor and tech-editor-fable, generated from one source (CF-12.2), edit every tech-writer output in place inside tech-writer's scope, carrying tech-writer's invariants (no invented APIs, flags, paths or versions; unsupported claims go under Unverified). lead.md step 4 becomes: the project's tech editor on every tech-writer output when it has one, otherwise the lead's own opus pass on external-audience output only.
