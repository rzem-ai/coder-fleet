## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Actions for Human are numbered items on a card; adding one moves the card to Blocked by Human, and while any is unticked only the human's web UI override takes it out (spec 39)
- [ ] #2 A card carries an acceptance criteria checklist and a Definition of Done checklist, each item tickable on its own; every numbered checklist counts from 0, the same in the card file, MCP tools, CLI and web UI, and tick or remove tools take the 0-based number (spec 40)
- [ ] #3 Project-wide default criteria and Definition of Done live in the board config and are read live; a tick on a default item is stored on the card by the item's text, so an edited or added default shows unticked; a defaults change never moves a card in Done or Released (spec 41)
- [ ] #4 A card can be a sub-issue of another, with a dotted id, and can list cards it depends on (spec 42)
- [ ] #5 A filter, through MCP, the CLI and the web UI, returns exactly the cards whose dependencies are all in Done or Released (spec 43)
