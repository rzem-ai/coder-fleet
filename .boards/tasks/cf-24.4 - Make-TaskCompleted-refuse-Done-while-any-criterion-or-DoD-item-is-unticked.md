Sub-issue 4 of 4 of CF-24 (spec docs/specs/CF-24.md, approved 2026-09-30). This lands last, after sub-issue 2's backfill, because otherwise it blocks Done on every open card that has no criteria. Today `board-task-completed.sh` moves a card to Done without reading it; CF-64 reached Done on 2026-09-29 with all five criteria unticked. Decisions carried forward (CF-24 comment #12): the gate also governs the lenient no-result path, which is this repo's normal path (OQ3). A Definition of Done item that does not apply is ticked with `not applicable: <reason>` (OQ9). `task view <id> --json` returns `.task.acceptanceCriteria[]` and `.task.definitionOfDone[]`, and new hook code must be safe under errexit.
