No case covers a use-mode reviewer's memory, or a break-mode or use-mode reviewer's memory in a registered worktree. CF-192 pinned the modes and CF-183.2 pinned the registered worktree; the join of the two is unpinned. The code is right today because the memory allow (enforce-agent-scope.sh:557) runs before the mode rule.
