## Description

What was still open on CF-184 after its one review round and one fix round (review round 2 on bf52d01 approved with follow-ups, 8 Nov 2026).

A card taken from Next can sit in In Progress with neither a lead `started` comment nor a recorded order (an evaluator contract, spec-writer or researcher spawn moves it there, and the lead writes `started` late), so every later drain skips it as `not ordered` and Next no longer lists it.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A card the human ordered through Next and that reached In Progress before its `started` comment is counted as ordered by drain - from evidence the fleet already leaves (a lead-cut branch starting with the card's id, a `Contract:` comment, or lead.md writing `started` before the first spawn) - and never skipped as `not ordered` for good
- [ ] #2 drain.md's branch rule matches a card's own branch and its sub-issues' branches without contradiction (the id lower-cased followed by `-` or `.`)
- [ ] #3 drain.md says what drain does with a card whose sub-issues are all built but which does not name each PR
- [ ] #4 docs/fleet-design.md and help-boards describe the `not ordered` skip instead of saying drain carries on every unheld In Progress card
